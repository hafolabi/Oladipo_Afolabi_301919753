# Sources and resources

The original planning references are from the official PostgreSQL and MongoDB documentation and were checked on **26 October 2026**. PostgreSQL design references and PGlite documentation were consulted for Portfolio 1 on **27 October 2026**. PostgreSQL query and indexing references were consulted for Portfolio 2 on **29 October 2026**.
