# AI Use Declaration

Oladipo Afolabi selected the Bank / Fintech case study for AfolabiPay.

I developed the AfolabiPay portfolio with assistance from OpenAI Codex when I requested suggestions with design, SQL and JavaScript logics, diagrams, and automated checks. For example, the customer `status` constraint and `updated_at` trigger were added and checked against the existing queries and transaction tests.
